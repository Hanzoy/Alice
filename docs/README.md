# Alice 项目文档

本目录是 Alice 后续设计和开发的权威文档入口。README 负责快速启动，这里负责记录已经确认的设计、当前真实实现状态和开发方式。

## 文档索引

- [架构与设计决策](ARCHITECTURE_AND_DECISIONS.md)：整理此前讨论形成的产品定义、Alice Core 边界、组件、Blueprint、Execution、Task、记忆、模型和存储决策。
- [实现状态与路线图](IMPLEMENTATION_STATUS.md)：区分已经实现、基础实现、尚未实现和建议的后续优先级。
- [家庭 Git 开发指南](HOME_DEVELOPMENT.md)：在另一台电脑克隆、启动、开发、测试、提交和备份时使用。

## 文档维护规则

1. 设计改变时，先修改“架构与设计决策”，再修改代码。
2. 功能完成后，同步修改“实现状态与路线图”，不能只修改 README 中的宣传描述。
3. “目标设计”与“当前实现”必须分开书写；存在接口不等于产品功能已经完成。
4. 重要决策记录原因和边界，避免以后重复讨论已经确认的问题。
5. 密钥、数据库备份和用户数据不得提交到 Git。
